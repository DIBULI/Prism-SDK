# Prism SDK 1.0.0 更新说明

更新发布日期：2026-09-04

## 兼容关系

- SDK Release Tag：`v1.0.0`
- Host SDK 运行时/ABI：`1.0.0`
- 支持的设备 Agent：`1.0.0`
- 已验证的 sensor-board：`0.4.25`
- USB 协议：`1`
- Runtime API：`5`

全部二进制均采用 SDK 1.0.0 源码和 ABI 基线，运行时报告 Host SDK 1.0.0，并
继续严格要求 Agent 1.0.0。

## 更新后的发布内容

- Linux x86-64、Linux ARM64、macOS ARM64 和 Windows x64 动态库。
- Linux x86-64 和 ARM64 静态库。
- `runtime/ros/linux-arm64` 通用 ARM64 静态 CMake 前缀；该产物在 Ubuntu
  20.04/GCC 9 下编译，并在使用方的 Ubuntu/ROS 环境中解析 Threads、libusb
  和 OpenSSL。
- 一份适用于 Ubuntu 20.04、22.04、24.04 和 26.04 的
  `runtime/ros/linux-x64` 动态 CMake 前缀；其 `.so` 采用 Ubuntu 20.04/
  GCC 9 ABI 基线，并静态包含 OpenSSL，以避免 OpenSSL 1.1/3.x 运行时冲突。
- 全例子和静态链接的原生 Linux ARM64 CI 覆盖。

## 升级方法

请整体替换 SDK checkout 或发布压缩包，不要在不同构建之间单独复制头文件或库。
普通 Linux ARM64 程序可选择 `runtime/linux-arm64`；ROS Adapter 在 ARM64
上使用 `runtime/ros/linux-arm64`，在 x86-64 上使用
`runtime/ros/linux-x64`。

更新后清理使用方的 CMake 缓存并重新编译。设备已经运行 Agent 1.0.0 和
sensor-board 0.4.25 时，不需要更新设备固件。
