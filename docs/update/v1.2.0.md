# Prism SDK v1.2.0

## What's included

These are the cumulative features and improvements included in 1.2.0.

- USB and RK-local device access, versions/status, persistent configuration and Wi-Fi controls.
- Camera images/metadata, onboard IMUs and MID360/MID360S/XT32 LiDAR acquisition.
- Exposure/gain controls, time synchronization, raw data recording integration and runnable examples.
- Keep healthy sensor streams running when another sensor or camera is missing.
- Improve acquisition reliability after explicit clock synchronization.
- Add matching Host and RK-local controls for RTK/CORS, LiDAR standby/wake,
  raw dataset downloads and background Sensor Board updates.
- Support receiver-native GNSS/RTK results, device diagnostics and unified
  automatic camera exposure.
- Refresh the camera and time guides, including internally aligned IMU output
  with the matching device firmware. Internal alignment does not imply UTC lock.
- Retire the previous raw/smoothed navigation API; use receiver-native results.
- Add original GNSS observation/ephemeris and module CORS byte access with gap metadata.
- Add MID360S normal/low-speed controls and improve receiver-query reliability.
- Improve capture restart reliability with the matching device update.

Use SDK/Agent **1.2.0** and the matching **0.4.27** device firmware. Replace
headers and libraries together and rebuild applications. Firmware behavior
requires the corresponding firmware update; installing an SDK does not flash it.

Linux: glibc 2.31+. macOS: Apple Silicon, macOS 13+. Windows: x64.
This refresh updates headers and runtime libraries together; Runtime API 18 is
retained and the new functions use separately versioned extensions.
