# Prism SDK v1.2.0

- Add matching Host USB / RK-local raw dataset list, manifest, bounded chunk read and download APIs. SDK exports original format only; no ROS1/ROS2 bag conversion or ROS offline download API.
- Add 64-bit offsets, chunk CRC32, file-change detection, cancellation and exclusive destination creation. DatasetRuntimeApi v1 is a separate extension; RuntimeApi v18 is unchanged. Requires the refreshed Agent 1.2.0 build.

- Includes a header-only GCC 9/11 compatibility adjustment and numeric-parser regression test, without changing the public interface or binary ABI.
- Update Host and RK-local C++ SDKs together for Agent **1.2.0** and Sensor Board **0.4.27**.
- Add unified CORS read/save and explicit RTK start/stop APIs, with generation-bound GGA consent and timeout/error reporting.
- Add RTK-module versions, control/4G status, current TimeSync modes, GNSS receive diagnostics and observation streams for receiver-native sky/trajectory display.
- Publish current XT32/LiDAR line-field and camera metadata/exposure interfaces.
- Remove the retired Agent `raw/smoothed` navigation interface; read receiver-native results instead.
- Refresh public headers, Linux x64/ARM64 shared/static libraries, ARM64 RK-local archive, macOS ARM64 dylibs and Windows x64 DLL from one source commit.
- Update Chinese/English guides and compile-checked examples, including RTK-module controls.

Compatibility: exact Agent **1.2.0** handshake; wire protocol **1**; Windows Runtime API **18**, RTK-module control extension **1**. Replace all headers/libraries and rebuild. Linux uses the Ubuntu 20.04 ABI baseline; macOS targets Apple Silicon/macOS 13+; Windows targets x64/MSVC 14.x.

Source: `DIBULI/Prism-agent@d7161c93baa4e652c2cdbbefb1e9922c6327c244`.
