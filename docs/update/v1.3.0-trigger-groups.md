# 1.3.0: 415M shared trigger groups

The matched Agent forwards the Sensor Board PRC4 `trigger_sequence` to direct
RAW12 deliveries. `Raw12Image::trigger_sequence` is the shared four-camera group
ID; `frame_id` remains the individual camera's native counter. The outer USB
transfer ID is still used for ACK, not image grouping. For v1 envelopes or
unknown trigger association, `trigger_sequence == 0`. Do not invent a shared
group by equating camera counters or arrival order.

Associate images using capture-session generation, nonzero trigger sequence,
and equal validated trigger timestamps. A new capture invalidates pending
groups. Timestamp values do not assert UTC synchronization. Missing/late images
must not be filled using images from another group.

Direct RAW PRG1/PRZ1 envelopes support version2 with a16-byte extension:

| Field | PRG1 v2 | PRZ1 v2 |
| --- | --- | --- |
| Header size | 80 | 64 |
| Native source frame | offset24 | offset24 |
| Shared trigger sequence | offset64 | offset48 |
| Reserved zero bytes | offsets68–75 | offsets52–59 |
| Header CRC32 | offset76 | offset60 |

The header CRC is IEEE CRC32 over all preceding header bytes. Encoded and fully
decoded pixel CRC checks are unchanged. RAW12 resolution/precision, codec
payloads, source counters, and ACK protocol are unchanged. Unknown timing uses
mode0 with zero timestamp and zero trigger sequence; known mode4 requires both
nonzero. Version1 remains readable. Ordinary Web/TF thumbnail delivery retains
its original format; this does not add RAW decoding to Web previews.

Update Agent and consuming SDK/Viewer together. Older decoders explicitly
reject the new envelope. This SDK change is in inline public decoding helpers;
Runtime API19 and transport library ABI/binaries are unchanged. Rebuild
consumers with updated headers. A1.3.0 version number alone does not establish
that an older installed Agent/Viewer contains this revision.

Protocol/header corruption and full RAW decoder tests are offline checks,
not physical-device qualification.
