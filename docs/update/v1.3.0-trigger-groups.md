# 1.3.0: 415RSV0 shared trigger groups

The current native RAW8 path forwards the Sensor Board's shared trigger ID.
`RawImage::trigger_sequence` identifies the four-camera trigger group;
`frame_id` remains the individual camera's source counter. The USB transfer
ID is used for ACK, not image grouping.

Associate images using capture-session generation, a validated nonzero trigger
sequence, and equal validated trigger timestamps. A new capture invalidates
pending groups. Never replace missing images with images from another group.
Timing mode 4 names a common external-trigger edge; it does not establish UTC.
Mode 0 means unknown timing; modes 1–3 carry no common trigger association.

The public profile path accepts native 5120×3072 PRG8/Rice images (wire format
0x82). The version-1 header is 80 bytes: source frame at byte 24, timestamp at
byte 40, encoded CRC at byte 48, trigger sequence at byte 52, header CRC at
byte 76. The header CRC covers the full 80-byte header with its CRC field zeroed.
Encoded payload and fully decoded original pixels have separate CRC checks.
Each original pixel occupies exactly one byte; no RAW12 expansion is performed.
See [RAW8 integration and example](../guides/network-raw.md).

Earlier PRG1/PRZ1 RAW12 envelopes are retired from this profile decoder.
Update matched Agent, SDK and Viewer together. All platform libraries in this
refresh are rebuilt together, while Runtime API 19 remains unchanged.
Same-version older binaries are not interchangeable with the new headers.

Web previews remain thumbnails. Recording completion, CRC warning status and
full-pixel validation are separate results. Offline protocol tests are not
physical-device endurance qualification.
