# Prism SDK 1.1.0

- Host SDK 1.1.0 / Runtime API 12; requires Agent 1.1.0, qualified Sensor Board 0.4.26.
- Publishes matching Linux x64/ARM64 shared and static libraries, macOS ARM64
  libraries, Windows x64 DLL, and installed CMake prefixes for Linux consumers.
- Adds the RK-local SDK C++ header, ARM64 archive, CMake target, Camera/IMU capture
  and read-only GNSS status examples. No private implementation source is included.
- Updates live GNSS/PPS, RTCM2/3 status and correction input, raw and independently
  smoothed RTK navigation, and Host rover RTCM recording interfaces.
- Documents Sensor Board time ownership and rejection of host clock updates
  while GNSS is synchronized. Keeps PPS validity/width; no public RK-PPS quality API.

Replace headers and libraries together and rebuild consumers. Old Agents are
not supported. See [new interfaces](../gnss-rtk.md), [RK-local usage](../rk-local-sdk.md)
and [build provenance](../../ORIGIN.md).
