# Prism SDK 1.0.2 update notes

Release date: 2026-09-04

## Version scope

- Distribution release: `1.0.2`
- Host SDK runtime/ABI: `1.0.0`
- Required device Agent: `1.0.0`
- Qualified sensor-board: `0.4.25`
- USB protocol: `1`
- Runtime API: `5`

Prism SDK 1.0.2 is packaged from the established 1.0.0 SDK source and ABI
baseline. It is a distribution update, not a wire-protocol or public-API
revision. The libraries therefore continue to report Host SDK 1.0.0 and retain
the strict Agent 1.0.0 handshake.

## Changes since distribution 1.0.0

- Added Linux ARM64 shared and static libraries compiled from the Host SDK
  1.0.0 source baseline.
- Added a portable Linux ARM64 static CMake prefix at
  `runtime/ros/linux-arm64`. It is built on Ubuntu 20.04 with GCC 9 and resolves
  Threads, libusb, and OpenSSL in the consuming Ubuntu/ROS environment.
- Added complete x86-64 CMake prefixes for Ubuntu 20.04, 22.04, 24.04, and
  26.04 under `runtime/ros`.
- Extended CI to build all examples on native Linux ARM64 and verify both Linux
  static-library variants.
- Kept the public headers, SDK/Agent compatibility, Runtime API, and USB
  protocol unchanged.

## Upgrade

Replace the complete SDK checkout or archive; do not copy individual headers or
libraries between releases. Consumers using the desktop Linux layout may select
`runtime/linux-arm64`. ROS Adapter builds should use
`runtime/ros/linux-arm64` on ARM64 and the matching Ubuntu prefix on x86-64.

After updating, clear the consumer's CMake cache and rebuild. No device firmware
update is required when the device already runs Agent 1.0.0.
