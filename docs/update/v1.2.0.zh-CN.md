# Prism SDK v1.2.0

## 本版本包含的功能

以下汇总 1.2.0 的累计功能与改进，并非仅列最后一次更新。

- USB 与 RK-local 设备访问、版本/状态查询、持久配置和 Wi-Fi 控制。
- 相机图像/元数据、板载 IMU 及 MID360/MID360S/XT32 雷达采集。
- 曝光/增益控制、时间同步、原始数据记录接入和可运行示例。
- 单个相机或传感器缺失时，其余正常数据流继续采集。
- 改善显式校时后开始采集的可靠性。
- 补齐 Host 与 RK-local 的 RTK/CORS、雷达待机/唤醒、原始数据集下载和 Sensor Board 后台升级接口。
- 支持接收机原生 GNSS/RTK 结果、设备诊断及统一自动曝光。
- 更新相机和时间说明，补充配套固件的内部对齐 IMU 输出行为；内部对齐不代表 UTC 授时成功。
- 移除旧 raw/smoothed 导航接口，改用接收机原生结果。

配合 SDK/Agent **1.2.0** 和对应 **0.4.27** 固件使用。头文件与库须同时更新，应用需重新编译。
固件功能需要另行更新对应固件，安装 SDK 不会自动刷写设备。

支持 Linux glibc 2.31+、macOS 13+ Apple Silicon、Windows x64。
本次文档整理不修改公开接口、ABI 或运行库。
