# Prism SDK v1.2.0

## 单路传感器缺失容错

- Host SDK 新增共享相机组帧器，保留部分帧中的完整 JPEG；缺失／损坏槽位留空，超时后只归还一次 ACK，不能补旧图像或伪造时间。
- RK-local 同步支持部分相机帧，内部完成超时和 ACK 管理；示例中单路缺失不再中止其他数据流。
- RK-local 静态库启用 PIC，支持 ROS 链接。接口签名、Agent 握手 1.2.0 和 Runtime API 18 不变。
- Wi-Fi 查询、启停及持久化接口不变；匹配 Agent／镜像使用独立热点服务。旧镜像仅替换 Agent 二进制不够，还需安装配套 helper／service。
- 真实相机时钟缺失容错需要配套 Sensor Board 0.4.27 固件；共享传输断开或显式停止仍会结束采集。见[独立数据流说明](../guides/stream-resilience.md)。

- 新增 Host/RK-local 一致的 C++ Sensor Board 后台维护接口和任务状态。
  停止采集后无需停止 Agent/Web；提供同版本跳过、force、上传 SHA-256 校验、
  重启版本确认和 RK-local 独立维护通道。需要匹配的新 Agent 1.2.0 构建，
  不修改 Sensor Board 固件；Windows Runtime API v18 表不变，新接口采用直接 C++ 链接。
  详见[维护接口](../guides/firmware-update.md#agent-managed-sensor-board-maintenance)。

- 修复校时后统一时间基准尚未就绪即验证的问题：丢弃零值、倒退及不可能的时间样本，
  最多等待六秒重读，不把无效时间或新的时间纪元用于第二次校时。配套 Agent 等待三个
  新鲜 PPS 对齐样本，并在 PHC 验证后再次确认就绪。Host/RK-local 的 TIME_SET 至少
  等待 35 秒；接口签名和线协议不变，不需更新 Sensor Board。本次不修复 UTC 保持或后续时间回退。
- 修复 Host USB 校时期间心跳超时退出、随后开始采集可能自动停止的问题。
  `synchronizeSystemTime()` 在设备空闲校时期间暂缓发送心跳，成功或异常退出后恢复发送，
  保留用户原来的心跳开关和间隔，不再需要通过断开重连恢复这一异常。
  校时失败仍如实报错；接口、ABI、采集期间的心跳超时保护均不变。
  RK-local/Web 不使用这条 USB 心跳线程；仅心跳这一项修复无需更新设备固件。
  本次不处理时间回退或 UTC 保持问题。详见[时间同步说明](../guides/time-sync.md)。
- SDK 文档按快速开始、接口参考、功能指南、示例、版本说明重新组织，合并 GNSS/RTK、
  时间同步及雷达专题，修复导航，并将本地链接/锚点检查纳入包校验。
  此前的文档整理不改变 SDK 头文件、库或 ABI。
- 新增 MID360/MID360S/XT32 独立硬件状态查询、待机、唤醒接口；Host 与 RK-local
  C++ 方法一致，Windows 增加独立 DLL 扩展 v1。普通采集启停不变，要求所有采集停止；
  超时表示结果未确认，不当作待机成功。详见[雷达待机](../guides/lidar.md#standby-wake)。
- 新增 Host USB / RK-local 同名原始数据集列表、清单、分块读取和下载接口。SDK 只导出原始格式，不转换 ROS1/ROS2 bag；ROS Adapter 不提供离线下载。
- 支持 64 位偏移、CRC32 校验、文件变化检查、取消和禁止覆盖。独立 DatasetRuntimeApi v1 扩展不改变 RuntimeApi v18；设备需更新到包含该接口的 Agent 1.2.0 构建。

- Host 与 RK-local C++ SDK 同步升级，匹配 Agent **1.2.0**、Sensor Board **0.4.27**。
- 新增统一 CORS 读取/保存、RTK 启停接口，显式授权 GGA，校验配置代次并报告超时和执行错误。
- 支持 RTK-module 版本、控制/4G 状态、最新 TimeSync 模式、GNSS 接收诊断及天空图/接收机定位报文。
- 更新 XT32、LiDAR line 字段、相机元数据和曝光接口。
- 移除 Agent 旧 `raw/smoothed` 导航接口，改用接收机原生结果。
- 所有平台库与公共头文件使用同一源码提交，补齐中文/英文说明和可编译的控制示例。
- 补充 GNSS 解析头文件的 GCC 9/11 兼容性修正与解析回归测试，不改变接口或 ABI。

要求 Agent **1.2.0**，协议 **1**，Windows Runtime API **18**、RTK-module 控制扩展 **1**。
必须同时替换头文件和库并重新编译。Linux 采用 Ubuntu 20.04 ABI 基线；macOS 为 Apple Silicon/macOS 13+；Windows 为 x64/MSVC 14.x。
