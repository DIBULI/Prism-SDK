# Prism SDK v1.2.0

- Host 与 RK-local C++ SDK 同步升级，匹配 Agent **1.2.0**、Sensor Board **0.4.27**。
- 新增统一 CORS 读取/保存、RTK 启停接口，显式授权 GGA，校验配置代次并报告超时和执行错误。
- 支持 RTK-module 版本、控制/4G 状态、最新 TimeSync 模式、GNSS 接收诊断及天空图/接收机定位报文。
- 更新 XT32、LiDAR line 字段、相机元数据和曝光接口。
- 移除 Agent 旧 `raw/smoothed` 导航接口，改用接收机原生结果。
- 所有平台库与公共头文件使用同一源码提交，补齐中文/英文说明和可编译的控制示例。

要求 Agent **1.2.0**，协议 **1**，Windows Runtime API **18**、RTK-module 控制扩展 **1**。
必须同时替换头文件和库并重新编译。Linux 采用 Ubuntu 20.04 ABI 基线；macOS 为 Apple Silicon/macOS 13+；Windows 为 x64/MSVC 14.x。

源码提交：`DIBULI/Prism-agent@d10fdcfc7919c082ad974bb79487d9c3c02cbee9`。
详见[来源](../../ORIGIN.md)、[CORS 控制](../rtk-module-control.md)和[RK-local 差异](../rk-local-sdk.zh-CN.md)。

Release 附件提供包含所有平台的 `.tar.gz`、`.zip` 和 SHA-256 校验文件；不包含固件、录制数据或设备测试报告。
