# Prism SDK 1.3.0

[English](v1.3.0.md) · [文档目录](../README.zh-CN.md)

配套 SDK / Agent **1.3.0** 和适合设备的 Sensor Board **0.5.2** 升级包。
头文件与库须同时更新，应用须重新编译。`DeviceInfo` 增加型号字段，
Runtime API 因此升为 **19**，独立网络扩展为 **4**，profile/连续曝光扩展为 **1**。
本次按用户要求更新同名 v1.3.0 修订；不要混用早期同版本头文件或库。

本次缺目修订更新 JPEG 帧组装头文件：使用每帧有效元数据中的相机成员集合，
只等待本帧实际声明的相机；缺失路保持空，不复制旧图、不阻塞正常路。
损坏／未完成的已声明图像仍明确报告，ACK 保持每帧一次。
Host 与 ROS 两种架构的头文件同步；运行库二进制和 ABI 未改变。
已包含此前网络相机／IMU 示例更新。该行为需配套支持缺目的设备固件，
不补齐旧协议，也不代表本次已经完成实机验收。

升级旧程序前请阅读 [1.2.x → 1.3.0 API 逐项变更与迁移示例](v1.3.0-api-changes.md)。
新增[连续曝光行数接口](v1.3.0-live-rows.md)与[Web 密码网络认证](v1.3.0-network-web-password.md)。

本次修订新增[原生行数/增益控制与共同触发时间](v1.3.0-native-camera-control.md)，
CameraControl Runtime API 为 1。415M 使用独立自动曝光/自动增益、手动整数行数、
手动增益及上下限；支持空闲暂存和采集中异步更新。配置接受值与逐帧观测值分开，
不把配置值当实测曝光。保留 41M3 旧接口，不将它作为新版 415M 的降级路径。

- 可直接查询设备型号，不再用 USB 路径、名称或 IP 猜测；旧 v4 响应返回 Unknown，
  畸形响应仍报错。
- USB 有界异步接收保留普通读超时前收到的部分数据，继续校验组帧完整性。
- 按当前要求使用明文 TCP 网络连接，复用 Client API；token 和数据不加密，
  仅用于可信局域网/热点。SDK、设备网关和应用须配套更新。按会话协商帧率上限，
  不修改持久化相机设置。
- 支持独立无损 RAW12 组帧和 PRG1/PRZ1 解码，保留全部 12 位有效数据并校验完整性。
- 具备对应完整升级器的设备可用单包更新 Agent、Web 和网络服务；
  不支持的旧设备在写入前被拒绝，不自动进行旧版引导升级。
- RK-local 公共接口和 ARM64 库同步更新。

参见[接口与示例](../guides/network-raw.md)、[升级语义](../guides/firmware-update.md)。
构建与发行包测试不等于新增实机验收；本次 SDK 同步不会刷写、启停或配置设备。
IMU 硬件 DMA、PTP 时标策略须由配套设备软件提供，安装 Host SDK 不会更改它们。
