# Prism SDK 1.0.0 update notes

Updated release date: 2026-09-04

## Compatibility

- SDK release tag: `v1.0.0`
- Host SDK runtime/ABI: `1.0.0`
- Supported device Agent: `1.0.0`
- Qualified sensor-board: `0.4.25`
- USB protocol: `1`
- Runtime API: `5`

All binaries use the SDK 1.0.0 source and ABI baseline. They report Host SDK
1.0.0 and retain the strict Agent 1.0.0 handshake.

## Updated release contents

- Linux x86-64, Linux ARM64, macOS ARM64, and Windows x64 dynamic libraries.
- Linux x86-64 and ARM64 static libraries.
- A portable Linux ARM64 static CMake prefix at `runtime/ros/linux-arm64`, built
  on Ubuntu 20.04 with GCC 9. Threads, libusb, and OpenSSL are resolved in the
  consuming Ubuntu/ROS environment.
- One `runtime/ros/linux-x64` shared CMake prefix for Ubuntu 20.04, 22.04,
  24.04, and 26.04. Its `.so` uses an Ubuntu 20.04/GCC 9 ABI baseline and
  statically embeds OpenSSL to avoid OpenSSL 1.1/3.x runtime conflicts.
- Native Linux ARM64 CI coverage for all examples and static linking.

## Upgrade

Replace the complete SDK checkout or archive; do not copy individual headers or
libraries between builds. Consumers using the desktop Linux layout may select
`runtime/linux-arm64`. ROS Adapter builds should use
`runtime/ros/linux-arm64` on ARM64 and `runtime/ros/linux-x64` on x86-64.

After updating, clear the consumer's CMake cache and rebuild. No Agent or
sensor-board update is required when the device already runs Agent 1.0.0 and
sensor-board 0.4.25.
