# Prism SDK 1.1.0

- Host SDK 1.1.0 / Runtime API 12，严格要求 Agent 1.1.0，配套 Sensor Board 0.4.26。
- 成套更新 Linux x64/ARM64 动态库与静态库、macOS ARM64 库、Windows x64 DLL，
  以及供 Linux 使用方使用的 CMake 安装前缀。
- 新增 RK-local C++ 头文件、ARM64 静态库、CMake 接入，以及相机/IMU 采集和
  GNSS 状态查询示例；不发布私有实现源码。
- 更新 GNSS/PPS、RTCM2/3 改正流输入及格式状态、RTK 原始/独立平滑解，
  以及 Host rover 原始 RTCM 录制接口。
- Sensor Board 掌管时间；GNSS 同步时禁止主机校时。保留 PPS 有效性/脉宽，
  不公开 RK-PPS 精度诊断接口。

头文件和库必须一起替换并重新编译，不兼容旧 Agent。详见
[新增接口](../gnss-rtk.zh-CN.md)、[RK-local 使用说明](../rk-local-sdk.zh-CN.md)
和 [构建来源](../../ORIGIN.md)。
