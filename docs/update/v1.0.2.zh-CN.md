# Prism SDK 1.0.2 更新说明

发布日期：2026-09-04

## 版本范围

- 分发版本：`1.0.2`
- Host SDK 运行时/ABI：`1.0.0`
- 要求的设备 Agent：`1.0.0`
- 已验证的 sensor-board：`0.4.25`
- USB 协议：`1`
- Runtime API：`5`

Prism SDK 1.0.2 基于既有 SDK 1.0.0 源码和 ABI 基线打包。它是分发版本更新，
没有修改线协议或公开 API。因此库仍报告 Host SDK 1.0.0，并继续严格要求设备端
Agent 1.0.0。

## 相比 1.0.0 分发版本的改动

- 新增从 Host SDK 1.0.0 源码基线编译的 Linux ARM64 动态库和静态库。
- 新增 `runtime/ros/linux-arm64` 通用 ARM64 静态 CMake 前缀；该产物在
  Ubuntu 20.04/GCC 9 下编译，并在使用方的 Ubuntu/ROS 环境中解析 Threads、
  libusb 和 OpenSSL。
- 在 `runtime/ros` 下补齐 Ubuntu 20.04、22.04、24.04 和 26.04 的 x86-64
  CMake 前缀。
- CI 新增原生 Linux ARM64 全例子构建，并验证两种 Linux 架构的静态链接。
- 公共头文件、SDK/Agent 兼容版本、Runtime API 和 USB 协议均保持不变。

## 升级方法

请整体替换 SDK checkout 或发布压缩包，不要跨版本单独复制头文件或库。普通
Linux ARM64 程序可选择 `runtime/linux-arm64`；ROS Adapter 在 ARM64 上使用
`runtime/ros/linux-arm64`，在 x86-64 上使用对应 Ubuntu 版本的前缀。

更新后清理使用方的 CMake 缓存并重新编译。设备已经运行 Agent 1.0.0 时，不需要
升级设备固件。
