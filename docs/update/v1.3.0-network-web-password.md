# 1.3.0 网络认证修订：与 Web 登录密码一致

SDK 与 Viewer 均可通过 Wi-Fi 或有线连接；Wi-Fi Web 登录和 USB 保持不变。
不再使用旧 TLS 证书指纹配对或独立随机令牌。

- `NetworkOptions::token` 字段保留，值改为设备 **Web 管理员登录密码**，不是
  浏览器会话 Cookie。精确匹配，不自动去空格、不转小写。拒绝空值、控制字符
  和超过 128 字节的输入。当前 Web 规则未改动，不生成或修改设备密码。
- `NetworkRuntimeApi` 从 3 升为 4；核心 `RuntimeApi` 仍为 19。
  使用 `prism_usb_sdk_get_network_api(4)`，旧扩展返回不可用，禁止静默降级。
- 握手改为 `PRISM-NET/4 <password>\n`。设备端不再读取旧随机 token/cert 文件，
  不再提供 `--pairing` 输出凭据。旧文件原样保留，既不复制到包中也不主动删除。
- 失败尝试触发跨网络连接的 10 秒冷却；冷却期间正确密码也会被拒绝。
  不抢占已有会话、不自动重连或重放指令，Web 自身登录限速与会话保持原样。
- 相机网络上限维持有线 20 FPS、Wi-Fi/未知接口 10 FPS；原生低帧率保持不变。
  此上限不是吞吐量承诺，实际网络仍可能更慢。
- 升级器的只读健康探针同步升级为 `/4`，不打开采集会话。

网络仍为明文 TCP，密码和数据可被截获；现有 Web 密码较短且按序列号确定，
不等于强随机令牌或加密身份认证。只在可信网络使用，不暴露到公网。
Viewer 只在内存中使用密码，不写普通设置、命令行、URL 或日志。

必须成套更新 SDK 头文件/库、Viewer、设备网关及匹配升级器。
相同 1.3.0 版本号不代表旧构建具备这套协议。离线测试不能代替设备实测。
